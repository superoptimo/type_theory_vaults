## Untagged topics

None — every top-level topic in this book is squarely about dependent type
theory (judgments, contexts, universes, conservativity, models), so all fit
`type-theory`. This book is highly abstract/homotopy-theoretic and does not
touch unification, constraint solving, or abstract interpretation directly;
"Formalisation of 2LTT in Proof Assistants" gets a secondary
`automated-reasoning` tag only because it discusses using Lean's type-class
resolution (an elaboration mechanism) to track fibrancy — a loose connection
to the elaborator/unifier work in the standing project, not a strong one.
