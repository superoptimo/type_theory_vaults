# Homotopy Type Theory: Univalent Foundations of Mathematics — Guidelines

## Header

**Title:** Homotopy Type Theory: Univalent Foundations of Mathematics
**Author(s):** The Univalent Foundations Program (Institute for Advanced Study, Princeton)
**Publication:** Institute for Advanced Study, 2013 (first edition)

**Brief Summary:**
The book is a systematic first exposition of homotopy type theory (HoTT) and the univalent foundations program. It interprets types as spaces (higher groupoids) and identity types as path spaces, then adds the univalence axiom and higher inductive types to Martin-Löf type theory. Part I develops the type theory and its homotopical reading; Part II uses it as a foundation for homotopy theory, category theory, set theory and real analysis. An appendix gives the formal rules of the system.

**Intent of the Author:**
To present univalent foundations as a practical alternative to set theory for informal mathematics, written so that a reader needs no formal logic and no proof assistant. The authors also want to show, through many worked examples, a new style of "invariant" mathematical reasoning that can be machine-checked.

## Chapter Summaries

### Introduction (pp. 1–14)

**Summary:** Motivates the pairing of type theory with homotopy theory. It outlines the univalence axiom, higher inductive types, and the Univalent Foundations program, and gives a reading guide to the book.

**Key Definitions & Concepts:**
- **Type theory** (a foundation where objects are classified by primitive types, as in programming languages; here, Martin-Löf's dependent, predicative system)
- **Homotopy type theory** (reading $a : A$ as "$a$ is a point of the space $A$", and $a = b$ as a path in $A$; types behave as $\infty$-groupoids)
- **Univalence axiom** (equivalent types are equal, so isomorphic structures can be identified)
- **Higher inductive types** (inductive types that also have constructors for paths, which describe spheres, truncations and quotients directly)
- **Univalent foundations** (the program of using these ideas as a foundation of mathematics with computer-checkable proofs)

**Key Questions:**
1. In what sense is the homotopical reading "purely homotopical, not topological"? Which topological notions are not available?
2. Why can neither univalence nor higher inductive types be captured directly in classical set-theoretic foundations?

### Chapter 1: Type theory (pp. 17–58)

**Summary:** Introduces the type theory used throughout, including its basic type formers and the propositions-as-types reading. It ends with the identity type and path induction, which the rest of the book builds on. : [[Dependent-Type-Theory-Foundations|Link1]], [[Formal-Presentation-and-Metatheory|Link2]], [[Identity-Types-and-Equality|Link3]], [[Truncation-Levels-and-Modalities|Link4]]

**Key Definitions & Concepts by Section:**
- **1.1 Type theory versus set theory** — judgment (a statement like $a : A$ or $a \equiv b : A$ that is derived, not proved), judgmental equality $\equiv$ (definitional equality, distinct from the propositional identity type), typing context (a list of variable declarations), deductive system (rules that generate judgments, with no separate underlying logic)
- **1.2 Function types** — $\lambda$-abstraction ($\lambda x.\,\Phi : A \to B$), application, $\beta$- and $\eta$-rules, currying, the induction/recursion pattern of introduction, elimination and computation rules : [[Dependent-Type-Theory-Foundations|Link1]], [[Inductive-Types|Link2]]
- **1.3 Universes and families** — universe $\mathcal{U}$ (a type whose elements are types), Russell-style universes, cumulative hierarchy $\mathcal{U}_0 : \mathcal{U}_1 : \cdots$, typical ambiguity, type family $B : A \to \mathcal{U}$ : [[Dependent-Type-Theory-Foundations|Link]]
- **1.4 Dependent function types ($\Pi$-types)** — $\prod_{x:A} B(x)$ (functions whose codomain depends on the argument), polymorphic functions via a universe : [[Inductive-Types|Link]]
- **1.5 Product types** — $A \times B$ (pairs), recursor $\mathsf{rec}_{A\times B}$, induction principle $\mathsf{ind}_{A\times B}$, unit type $\mathbf{1}$, uniqueness principle : [[Dependent-Type-Theory-Foundations|Link]]
- **1.6 Dependent pair types ($\Sigma$-types)** — $\sum_{x:A} B(x)$ (pairs whose second component's type depends on the first), projections, type-theoretic axiom of choice
- **1.7 Coproduct types** — $A + B$ (disjoint union with $\mathsf{inl}$, $\mathsf{inr}$), empty type $\mathbf{0}$ : [[Dependent-Type-Theory-Foundations|Link]]
- **1.8 The type of booleans** — $\mathbf{2}$ (two elements $0_{\mathbf{2}}$, $1_{\mathbf{2}}$), its recursor and induction principle : [[Dependent-Type-Theory-Foundations|Link]]
- **1.9 The natural numbers** — $\mathbb{N}$ (zero and successor), recursor, induction principle, definition of addition by recursion : [[Dependent-Type-Theory-Foundations|Link1]], [[W-Types-as-Well-Founded-Trees|Link2]]
- **1.10 Pattern matching and recursion** — defining functions by equations as notation for applications of recursors : [[W-Types-as-Well-Founded-Trees|Link]]
- **1.11 Propositions as types** — a proposition is a type, and a proof is an element. Under this reading, $\to$ is implication, $\times$ is conjunction, $+$ is disjunction, $\Pi$ is $\forall$ and $\Sigma$ is $\exists$. Negation is $A \to \mathbf{0}$. : [[Dependent-Type-Theory-Foundations|Link1]], [[Propositions-as-Types-and-Logic|Link2]]
- **1.12 Identity types** — $a =_A b$ (the type of identifications), reflexivity $\mathsf{refl}_a$, path induction $J$ (to prove a property of all paths it suffices to prove it for $\mathsf{refl}$), based path induction, disequality : [[Dependent-Type-Theory-Foundations|Link1]], [[Identity-Types-and-Equality|Link2]], [[Inductive-Types|Link3]]

**Key Questions:**
1. How does judgmental equality differ from the identity type $a =_A b$? Why is the former not a type?
2. How do the recursor and the induction principle of an inductive type relate, and why is the dependent form needed for propositions-as-types reasoning?
3. Why does path induction not imply that every path is $\mathsf{refl}$?

**Summary:** Works out the homotopical structure forced on types by the identity type, and describes the paths in each type former. - **2.4 Homotopies and equivalences** — homotopy $f \sim g$ (a pointwise path), quasi-inverse, equivalence $A \simeq B$ : [[The-Homotopical-Interpretation-of-Types|Link]]
- **2.5 The higher groupoid structure of type formers** — theorems describing paths in each type former, introduced collectively : [[Higher-Inductive-Types|Link1]], [[The-Homotopical-Interpretation-of-Types|Link2]]
- **2.6 Cartesian product types** — paths in $A \times B$ are pairs of paths : [[Dependent-Type-Theory-Foundations|Link1]], [[Inductive-Types|Link2]]
- **2.7 $\Sigma$-types** — paths in $\sum_{x:A} P(x)$ are a path in $A$ plus a path over it via transport : [[Dependent-Type-Theory-Foundations|Link]]
- **2.8 The unit type** — $\mathbf{1}$ has contractible identity types : [[Dependent-Type-Theory-Foundations|Link]]
- **2.9 $\Pi$-types and the function extensionality axiom** — $\mathsf{happly}$ and the axiom that it is an equivalence, so pointwise-equal functions are equal : [[Equivalences-and-Univalence|Link]]
- **2.10 Universes and the univalence axiom** — $\mathsf{idtoeqv} : (A = B) \to (A \simeq B)$, univalence asserting that this map is an equivalence, $\mathsf{ua}$ : [[Equivalences-and-Univalence|Link]]
- **2.11 Identity type** — paths in identity types, transport in path families : [[Dependent-Type-Theory-Foundations|Link1]], [[Identity-Types-and-Equality|Link2]], [[Inductive-Types|Link3]]
- **2.12 Coproducts** — encode-decode proof that $\mathsf{inl}(a) = \mathsf{inl}(a')$ iff $a = a'$ and that $\mathsf{inl} \neq \mathsf{inr}$
- **2.13 Natural numbers** — encode-decode for $\mathbb{N}$ : [[Dependent-Type-Theory-Foundations|Link1]], [[W-Types-as-Well-Founded-Trees|Link2]]
- **2.14 Example: equality of structures** — semigroups and magmas, showing that univalence turns isomorphism into equality : [[Identity-Types-and-Equality|Link]]
- **2.15 Universal properties** — characterization of product, $\Sigma$ and $\Pi$ types by maps into or out of them : [[Constructive-Real-Analysis|Link1]], [[Higher-Inductive-Types|Link2]]

**Key Questions:**
1. How does $\mathsf{transport}$ make type families behave like fibrations, and what does $\mathsf{apd}$ add over $\mathsf{ap}$?
2. State univalence precisely. What does it say about the paths in a universe?
3. How does the encode-decode method prove that $\mathbb{N}$ has decidable equality of constructors?

### Chapter 3: Sets and logic (pp. 107–128)

**Summary:** Separates the types that behave like ordinary sets and propositions from general types. It shows how classical-looking logic can be recovered in HoTT through "mere propositions" and truncation.

**Key Definitions & Concepts by Section:**
- **3.1 Sets and $n$-types** — set (a type with $\mathsf{isSet}(A) :\equiv \prod_{x,y:A}\prod_{p,q:x=y} (p=q)$), $\mathbf{1}$, $\mathbf{0}$, $\mathbb{N}$ and $\mathbf{2}$ are sets : [[Truncation-Levels-and-Modalities|Link]]
- **3.2 Propositions as types?** — why interpreting every type as a proposition fails, using the axiom-of-choice and law-of-excluded-middle versions that would be inconsistent with univalence : [[Dependent-Type-Theory-Foundations|Link1]], [[Propositions-as-Types-and-Logic|Link2]]
- **3.3 Mere propositions** — $\mathsf{isProp}(P)$ (any two elements are equal), propositions are sets, $\mathsf{isProp}$ is itself a mere proposition : [[Propositions-as-Types-and-Logic|Link]]
- **3.4 Classical vs. intuitionistic logic** — $\mathsf{LEM}$ and its inconsistency with univalence in the unrestricted form, double-negation elimination
- **3.5 Subsets and propositional resizing** — subset $\{x : A \mid P(x)\}$, the resizing axiom (every mere proposition is equivalent to one in the lowest universe), $\mathsf{Prop}$ : [[Propositions-as-Types-and-Logic|Link]]
- **3.6 The logic of mere propositions** — $\wedge$, $\Rightarrow$, $\Leftrightarrow$, $\neg$, $\forall$ via closure of mere propositions, with $\vee$ and $\exists$ requiring truncation : [[Propositions-as-Types-and-Logic|Link]]
- **3.7 Propositional truncation** — $\|A\|$ (the universal mere proposition receiving a map from $A$), recursion principle into mere propositions : [[Propositions-as-Types-and-Logic|Link]]
- **3.8 The axiom of choice** — formulation with truncated $\exists$, difference from the type-theoretic choice for $\Sigma$ : [[Propositions-as-Types-and-Logic|Link]]
- **3.9 The principle of unique choice** — if each $x$ has a unique $y$ with $R(x,y)$, then a function exists : [[Propositions-as-Types-and-Logic|Link]]
- **3.10 When are propositions truncated?** — when to use $\|A\|$ versus a bare type, as a design question for definitions : [[Propositions-as-Types-and-Logic|Link]]
- **3.11 Contractibility** — $\mathsf{isContr}(A)$ (an element to which all others are connected by paths), contractible types as propositions, singleton contractibility : [[Propositions-as-Types-and-Logic|Link]]

**Key Questions:**
1. Why can't $\vee$ and $\exists$ be interpreted by $+$ and $\Sigma$ in a logic of mere propositions, and what does truncation repair?
2. Why is the unrestricted law of excluded middle inconsistent with univalence, while the version for mere propositions is only an optional assumption?

**Key Definitions & Concepts by Section:**

### Appendix A: Formal type theory (pp. 425–441)

**Summary:** Gives the rules of the type theory used in the book in two presentations, and states the main metatheoretic properties. : [[Constructive-Real-Analysis|Link1]], [[Set-Theory-in-Univalent-Foundations|Link2]]

**Key Definitions & Concepts by Section:**
- **A.1 The first presentation** — judgment forms ($\Gamma \vdash A : \mathcal{U}_i$, $\Gamma \vdash a : A$, $\Gamma \vdash a \equiv a' : A$), structural rules (variable, weakening, substitution), explicit rules for $\Pi$, $\Sigma$, $+$, $\mathbf{0}$, $\mathbf{1}$, $\mathbb{N}$, identity types and universes
- **A.2 The second presentation** — Tarski-style variant with explicit universe codes, and the generalized form where rules are written with judgments stated about telescopes, a style close to the one used in proof assistants
- **A.3 Homotopy type theory** — additional axioms and rules: univalence, function extensionality, higher inductive types
- **A.4 Basic metatheory** — admissibility of substitution, canonicity for the base theory, decidability of type checking, and the status of canonicity once axioms are added (open problem for univalence at the time of writing)

**Key Questions:**
1. Which structural rules (weakening, substitution) are derivable and which are primitive in the formal presentation?
2. Why does adding the univalence axiom as a postulate break canonicity, and what is the proposed remedy?
